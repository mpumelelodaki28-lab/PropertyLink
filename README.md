# PropertyLink
PropertyLink

Find. Connect. Move.

PropertyLink is a digital property marketplace designed to connect property buyers, renters, owners, landlords, and real-estate professionals in one platform.

The initial focus is South Africa, with the long-term goal of creating a broader property technology ecosystem.

What PropertyLink Will Offer

For Buyers and Renters

* Search for properties
* Filter properties by location, price, type, and bedrooms
* View property details and photos
* Contact property agents
* Request property viewings
* Save properties

For Property Owners and Landlords

* Create property listings
* Upload property photos
* Set prices and property details
* Receive enquiries
* Manage listings

For Property Agents

* Create professional profiles
* Manage property listings
* Receive customer enquiries
* Manage viewing requests
* Manage potential clients

Planned Features

* Property search
* Property listings
* Agent profiles
* Viewing requests
* Customer enquiries
* Favorites
* Property images
* Location-based search
* User accounts
* Business dashboards
* Property verification
* Notifications

Technology

The initial prototype will be built using:

* HTML
* CSS
* JavaScript
* Supabase
* GitHub Pages

Additional technologies may be introduced as the platform develops.

Project Vision

PropertyLink aims to become more than a property-listing website.

The long-term vision is to create a platform where people can discover properties and connect with the professionals and services involved in buying, renting, selling, and managing property.

Project Status

The project is currently being developed from the ground up.
